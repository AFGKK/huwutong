## 1. 测试目标与范围

### 1.1 测试目标

- 验证互物通系统所有核心功能模块的 API 端点是否正常响应（200/201）
- 验证前端管理后台各页面是否能正常加载数据
- 验证关键业务流程（License 创建→激活→管理、商品浏览→购物车→下单）是否完整
- 发现并记录遗留的问题

### 1.2 测试范围

| 覆盖范围 | 说明 |
|---------|------|
| **后端 API 端点** | 所有已注册路由的 HTTP 状态码验证 |
| **前端管理后台页面** | 主要页面的数据加载和交互验证 |
| **核心业务流** | License 生命周期、电商订单流、IM 通讯 |
| **不覆盖** | 第三方集成（支付网关实际回调）、SDK 端到端、性能测试 |

### 4.3 业务流测试

#### BFT-01 License 完整生命周期

```
前置条件：已有产品、客户
流程：
  1. 创建 License → POST /api/admin/licenses
  2. 查看 License 列表 → GET /api/admin/licenses?per_page=10
  3. 查看 License 详情 → GET /api/admin/licenses/{id}
  4. 挂起 License → POST /api/admin/licenses/{id}/suspend
  5. 恢复 License → POST /api/admin/licenses/{id}/restore
  6. 删除 License（进回收站）→ DELETE /api/admin/licenses/{id}
  7. 从回收站恢复 → POST /api/admin/licenses/{id}/restore
验证点：每个步骤返回 200/201
```

#### BFT-02 电商购物流程

前置条件：已有商品、SKU 库存

  3. 查看购物车 → GET /api/cart
  4. 获取购物车摘要 → GET /api/cart/summary
  5. 结算 → POST /api/cart/checkout
  6. 查看订单列表 → GET /api/orders

验证点：每一步返回 200/201

## 5. 测试执行计划

### 5.1 执行方式

| 方式 | 工具 | 说明 |
|------|------|------|
| **浏览器实测** | Playwright | 打开管理后台页面，检查组件加载和交互 |
| **API 直接调用** | 浏览器 fetch + Token | 验证后端端点状态码 |
| **PHP 语法检查** | `php -l` | 验证 PHP 文件语法 |

### 5.2 测试执行脚本

每个模块测试时，使用以下模板从浏览器控制台执行：

```javascript
// 快速测试模块的 API 端点示例
const token = /* 从 localStorage 获取 */;
const h = { 'Authorization': 'Bearer ' + token, 'Accept': 'application/json' };
async function test(name, url) {
  const r = await fetch(url, { headers: h });
  console.log(name, r.status);
}

// 测试用例
await test('模块名-用例1', '/api/path');
```

### 5.3 验收标准

| 等级 | 标准 |
|:----:|------|
| **P0 通过** | 该模块所有 P0 端点返回 200/201，前端页面无报错 |
| **P1 通过** | 该模块所有 P1 端点返回 200/201 |
| **模块通过** | 该模块 P0 + P1 端点全部通过 |
| **整体通过** | 所有 P0 模块通过率 ≥ 95%，P1 模块通过率 ≥ 85% |
