## 4. 数据库方案

### 4.1 MySQL 架构

- **生产**: 阿里云 RDS MySQL 8.0 (主从架构，1主2从)
- **容灾**: 跨区域灾备实例 (异步复制)
- **备份**: 每日自动备份 + Binlog 实时备份 (RPO < 5min)
- **连接池**: Laravel 连接池 + ProxySQL 中间件

### 4.2 Redis 架构

- **生产**: 阿里云 Redis 7.0 集群版
- **哨兵**: Sentinel 哨兵模式，自动故障转移
- **用途**: 缓存(90%) + Session(5%) + 队列(5%)

## 6. 网络与安全方案

### 6.1 网络拓扑

```
Internet → CDN/WAF → NLB → Kong Gateway → Service Mesh(Istio) → Pods
                                   │
                                   └→ 管理后台 (内网)
```

### 6.2 安全策略

| 层级 | 措施 |
|:----|:-----|
| **网络层** | VPC 私有网络 + 安全组 + 子网隔离 |
| **传输层** | TLS 1.3 + HSTS + mTLS 服务间通信 |
| **应用层** | WAF + API 限流 + CSP + CORS + 数据脱敏 |
| **数据层** | 存储加密(AES-256) + 传输加密(TLS) + 密钥轮换 |
| **运维层** | RBAC + Audit Log + Secret Manager + Vault |

## 7. CI/CD 流水线

### 7.1 流水线阶段

```
代码提交 → 代码扫描 → 单元测试 → 构建镜像 → 集成测试 → Staging部署 → E2E测试 → 生产部署
  │          │           │          │          │           │           │          │
  └── lint   └── sonar   └── phpunit └── docker └── pact    └── helm    └── pw     └── blue-green
      phpstan  secret      vitest    build       contract    upgrade     e2e        deploy
```

### 7.2 部署策略

- **生产**: 蓝绿部署 (Blue-Green) 零停机发布

- **回滚**: Helm rollback + 数据库 Migration 回退脚本

## 9. 容灾与高可用方案

### 9.1 SLA 目标

| 指标 | 目标 |
|:----|:----|
| 可用性 (Uptime) | 99.99% (年度停机 < 52min) |
| API P99 延迟 | < 200ms |
| 激活成功率 | > 99.9% |
| RPO (数据恢复点) | < 5min |
| RTO (恢复时间) | < 15min |

### 9.2 容灾策略

- **单区域故障**: 自动故障切换至备用区域 (GeoDNS + 多区域部署)
- **数据库故障**: 自动主从切换 (MySQL 半同步复制)
- **缓存故障**: 降级至数据库直接查询 (Circuit Breaker 模式)
- **服务降级**: 非核心功能优雅降级，保证激活链路可用

## 11. Docker Compose 本地开发

### 11.1 服务定义

```yaml
# compose.yaml (项目根目录)
services:
  app:        # Laravel App (php-fpm + nginx)
  queue:      # Horizon Queue Worker
  reverb:     # WebSocket Server
  scheduler:  # Cron/Schedule Runner
  mysql:      # MySQL 8.0
  redis:      # Redis 7.0
  mailpit:    # 开发邮件捕获
  minio:      # S3 兼容本地存储
```

### 11.2 启动方式

```bash
# 一键启动所有服务
docker compose up -d

# 仅启动数据库
docker compose up -d mysql redis mailpit

# 查看日志
docker compose logs -f app
```
