# T-21 微信小程序审核前功能测试清单

> 依赖：真实 AppID / AppSecret（管理后台「系统设置」或 `.env`）  
> 自检：`php scripts/verify-miniprogram.php`  
> 同步：`php scripts/sync-miniprogram-config.php`

## 环境

- [ ] 微信公众平台已创建小程序，拿到 AppID / AppSecret
- [ ] 管理后台 → 系统设置 → 微信小程序 已填写
- [ ] 已运行 `sync-miniprogram-config.php`
- [ ] request 合法域名已配 HTTPS（如 `https://88.huwutong.com`）
- [ ] **业务域名**已配（web-view 打开定价/帮助，如 `88.huwutong.com`）
- [ ] 微信开发者工具已导入 `miniprogram/` 目录
