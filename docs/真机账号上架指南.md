## 1. Flutter 真机推送 (D-28 / T-20)

### 1.1 Firebase 项目（控制台操作，约 5 分钟）

> 无法在本仓库内代替你登录 Google；请用浏览器完成下列步骤，再运行安装脚本。

| 步骤 | 操作 | 关键参数 |
|:----:|------|----------|
| 1 | 打开 [Firebase Console](https://console.firebase.google.com/) → **添加项目** | 名称建议 `huwutong`；Google Analytics 可先关闭 |
| 2 | 项目概览 → **添加应用 → Android** | 包名 **`com.huwutong.license`**（必须一致）→ 下载 `google-services.json` |
| 3 | 再添加应用 → **iOS**（可稍后） | Bundle ID **`com.huwutong.license`** → 下载 `GoogleService-Info.plist` |
| 4 | 齿轮 → **项目设置** → **服务账号** → **生成新的私钥** | 下载 `*-firebase-adminsdk-*.json` |

#### 一键落位（下载到「下载」文件夹后）

```powershell
powershell -File scripts/install-firebase-credentials.ps1 `
  -AndroidJson "$env:USERPROFILE\Downloads\google-services.json" `
  -IosPlist "$env:USERPROFILE\Downloads\GoogleService-Info.plist" `
  -ServiceAccount "$env:USERPROFILE\Downloads\<你的服务账号文件名>.json"
```

脚本会：

- 校验包名 / Bundle ID 为 `com.huwutong.license`
- 复制到 `mobile/android/app/google-services.json`、`mobile/ios/Runner/GoogleService-Info.plist`、`storage/app/fcm-credentials.json`
- 自动写入 `.env` 的 `FCM_PROJECT_ID` / `FCM_CREDENTIALS_PATH`

不传某个参数即可跳过（例如仅 Android 真机可先省略 `-IosPlist`）。

### 1.2 后端 .env（脚本会自动写；也可手改）

```env
FCM_PROJECT_ID=your-firebase-project-id
FCM_CREDENTIALS_PATH=storage/app/fcm-credentials.json
FCM_DRY_RUN=false
```

生产服务器可将路径改为绝对路径，例如 `/var/www/huwutong/storage/app/fcm-credentials.json`。

### 1.3 Android 真机

```bash
cd mobile
flutter pub get
flutter run --dart-define=API_BASE_URL=https://88.huwutong.com/api
```

登录后 App 会自动调用 `POST /api/device/fcm-token` 注册 Token。

### 1.4 iOS 真机（额外步骤）

1. Apple Developer → Certificates → 启用 **Push Notifications** capability。
2. Firebase Console → 项目设置 → Cloud Messaging → 上传 **APNs 认证密钥 (.p8)** 或证书。
3. Xcode → Runner → Signing & Capabilities → 添加 **Push Notifications**、**Background Modes → Remote notifications**。

### 1.5 推送验收

```bash
# 干跑：仅检查配置
php artisan fcm:test-push admin@example.com --dry-run

# 向已登录并注册 Token 的用户发送测试推送
php artisan fcm:test-push admin@example.com --title="真机测试" --body="FCM 联调成功"
```

## 4. 常见问题

| 现象 | 排查 |
|------|------|
| 真机收不到推送 | `verify-mobile-credentials.php`；用户是否有 `fcm_token`；Firebase 是否上传 APNs（iOS） |
| `google-services.json` 报错 | 包名须为 `com.huwutong.license`，与 Firebase 注册一致 |
| 小程序 `40029 code 无效` | AppID/AppSecret 不匹配；code 已用过（5 分钟有效） |
| 小程序域名报错 | 公众平台未配置 request 合法域名 |
| Fastlane 上传失败 | 首包是否手动上传；Service Account / API Key 权限是否足够 |
