## 二、本轮新发现

### P2-1 忘记密码接口存在用户枚举 — ✅ 已修复

- `POST /api/forgot-password`
  - 不存在邮箱 → `"The selected email is invalid."`
  - 存在邮箱 → `"验证码已发送到您的邮箱"`
- 响应差异可被用于批量探测注册邮箱（登录接口做了统一文案，此接口漏了）
- **修复**: 去掉 `exists:users,email`；无论是否注册均返回同一成功文案；仅对已注册邮箱发信；未注册时加轻微随机延迟

### P3-1 注册接口无限流 — ✅ 已修复

- 连续 3 次注册全部 201，无频率限制（对比登录有 5 次锁定机制）
- **修复**: `POST /api/register`、`/phone/register`、`/phone/send-code`、`/forgot-password` 等加 `throttle`（注册/发码 **5/分钟**）

### P3-2 license 仍允许 customer_id=null 创建（v3 遗留）

- 低危，**确认为合法业务场景**（生成待分配的 license 池），保持可空
