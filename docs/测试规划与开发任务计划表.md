### 2.2 架构关系（简图）

```
                    ┌─────────────────────────────────────┐
                    │         Laravel API + Reverb         │
                    └─────────────────────────────────────┘
           ┌──────────────┬──────────────┬────────────────┐
           ▼              ▼              ▼                ▼
    H5 响应式 Web    Flutter App    微信小程序(待建)   Electron/Tauri(待建)
    /  /portal       mobile/        miniprogram/       desktop/
    /build (PWA)     原生管理端      License 轻量版      桌面管理壳
```

> **说明**：互物通 **有 H5**，但是多套 Web 响应式/PWA，**不是**独立 uni-app 或 `/m/` 子域 H5 工程。

## 8. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| iOS 无 HTTPS 无法通话/录音 | H5 IM、WebRTC 失败 | 优先 D-02；H5 通话提示升级 HTTPS |
| 无 TURN 跨网失败 | 4G/外网通话不通 | D-09；短期同 WiFi 验收 |
| 微信小程序审核 | 类目/域名/隐私被拒 | D-31 先做查询；激活功能分版本提交 |
| Meilisearch 未启动 | 搜索回退 MySQL LIKE | D-34 优先；D-19 降级 UI |
| Ollama 无 GPU | 推理慢/超时 | 小模型优先；云端 API 作 fallback |
| 5000 QPS 未达标 | 性能承诺风险 | D-39 Octane+Redis；分接口压测 |
| ZAP 误报阻断 CI | 发布卡住 | D-41 调策略；中危警告、高危阻断 |
| Flutter 推送证书 | 真机收不到通知 | D-28 分 Android/iOS 分步验证 |
