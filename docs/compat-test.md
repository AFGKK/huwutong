## 八、测试流程

### 8.1 自动化测试命令

```bash
# PHPUnit 全量测试
php artisan test --parallel

# 指定 PHP 版本的测试
php8.2 vendor/bin/phpunit
php8.3 vendor/bin/phpunit

# 前端组件测试
npx vitest run

# E2E 测试 (Playwright)
npx playwright test

# 契约测试
php artisan pact:verify
```

### 8.2 Docker Compose 兼容性测试

```bash
# PHP 8.2 + MySQL 8.0 + Redis 6.x
docker compose -f docker-compose.compat.yml --profile php82-mysql80-redis6 up -d

# PHP 8.3 + MySQL 8.4 + Redis 7.x
docker compose -f docker-compose.compat.yml --profile php83-mysql84-redis7 up -d
```

### 8.3 CI 集成

兼容性测试已集成到 GitHub Actions 工作流中（`.github/workflows/compat-test.yml`），每次推送到 `main`/`release/*` 分支时自动在矩阵环境中执行。
