## 0. 上线前凭据清单（阻断项）

以下项**必须人工准备**，仓库内仅为占位，切勿把真实密钥提交到 Git。

| 类别 | 必填项 | 来源 | `.env` / 后台 |
|:-----|:-------|:-----|:--------------|
| 应用 | `APP_KEY` | `php artisan key:generate` | `.env` |
| 数据库 | `DB_PASSWORD` | 运维自建 | `.env` |
| Reverb | `REVERB_APP_KEY` / `REVERB_APP_SECRET` | 随机 32 位 hex | `.env` |
| HTTPS | Let's Encrypt 或商业证书 | DNS 已指向服务器 | Nginx |
| 支付宝 | `ALIPAY_APP_ID` / 私钥 / 公钥 | [开放平台](https://open.alipay.com) | `.env` 或系统设置 |
| Stripe（可选） | `STRIPE_SECRET` / `STRIPE_WEBHOOK_SECRET` | Stripe Dashboard | `.env` |
| 微信（可选） | `WECHAT_*` 商户与证书 | 微信商户平台 | `.env` |
| SMTP | `MAIL_HOST` / 用户名密码 | 邮件服务商 | `.env` 或系统设置 |
| 短信 | `ALIYUN_SMS_*` | 阿里云短信 | `.env` 或系统设置 |
| 微信小程序 | AppID / AppSecret | 微信公众平台 | 系统设置「微信小程序」 |
| FCM（Flutter） | Firebase 服务账号 / 客户端配置 | Firebase Console | `.env` + 客户端文件 |
| GitHub Deploy | `VPS_SSH_KEY` | 部署机 SSH 私钥 | GitHub Secrets |

**安全约定**

- 生产 `.env` 仅存在于服务器；本地用 `.env.production.example` 作模板。
- 支付/短信私钥、微信 AppSecret、FCM JSON **永不入仓**。
- 首次上线可用 `PAYMENT_DRIVER=mock` + `SMS_FALLBACK_TO_LOG=true` 做冒烟，再切真实通道。

## 1. 部署架构概览

```
                          ┌─────────────────────┐
                          │   Cloudflare / DNS   │
                          │  88.huwutong.com     │
                          └──────┬──────────────┘
                                 │ 443 (HTTPS)
                                 ▼
                      ┌─────────────────────┐
                      │    Nginx (反代)      │
                      │  SSL 终止 / 静态资源  │
                      └──┬──────────────┬───┘
                         │ /app (wss)   │ / (https)
                         ▼              ▼
              ┌──────────────────┐  ┌──────────────────┐
              │  Laravel Reverb  │  │  PHP-FPM 8.3     │
              │  WebSocket 服务   │  │  Laravel App     │
              │  127.0.0.1:8080  │  │  unix socket     │
              └──────────────────┘  └──────┬───────────┘
                         │                  │
                         ▼                  ▼
              ┌──────────────────────────────────────┐
              │           Redis (Session/Queue/Cache) │
              │           PostgreSQL (主数据库)        │
              └──────────────────────────────────────┘

Supervisor 守护:
  ├── huwutong-reverb   (1 进程)  → artisan reverb:start
  └── huwutong-worker   (N 进程)  → artisan queue:work

系统 Cron:
  └── * * * * * php artisan schedule:run
```

## 2. D-01 · Reverb WebSocket 生产配置 + Supervisor 守护

### 2.1 安装 Supervisor 配置

配置文件已就绪：

- `deploy/supervisor/huwutong-reverb.conf`
- `deploy/supervisor/huwutong-worker.conf`

```bash
sudo cp deploy/supervisor/huwutong-reverb.conf /etc/supervisor/conf.d/
sudo cp deploy/supervisor/huwutong-worker.conf /etc/supervisor/conf.d/

# 若项目路径不是 /var/www/huwutong，先 sed 替换 conf 内路径
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start huwutong-reverb:*
sudo supervisorctl start huwutong-worker:*
sudo supervisorctl status
```

预期：

```
huwutong-reverb:huwutong-reverb_00   RUNNING
huwutong-worker:huwutong-worker_00   RUNNING
huwutong-worker:huwutong-worker_01   RUNNING
```

### 2.2 Reverb 配置 (`.env`)

```ini
BROADCAST_CONNECTION=reverb

REVERB_APP_ID=hwt-prod
REVERB_APP_KEY=<32位随机字符串>
REVERB_APP_SECRET=<32位随机字符串>

REVERB_SERVER_HOST=0.0.0.0
REVERB_SERVER_PORT=8080

REVERB_HOST=88.huwutong.com
REVERB_PORT=443
REVERB_SCHEME=https

VITE_REVERB_APP_KEY="${REVERB_APP_KEY}"
VITE_REVERB_HOST="${REVERB_HOST}"
VITE_REVERB_PORT="${REVERB_PORT}"
VITE_REVERB_SCHEME="${REVERB_SCHEME}"
```

生成密钥：

```bash
php -r "echo 'REVERB_APP_KEY=' . bin2hex(random_bytes(16)) . PHP_EOL;"
php -r "echo 'REVERB_APP_SECRET=' . bin2hex(random_bytes(16)) . PHP_EOL;"
```

修改 `VITE_REVERB_*` 后必须重新 `npm run build`。

### 2.3 验证 Reverb

```bash
ss -tlnp | grep 8080
# 8080 仅本机监听，勿对公网开放

curl -i -H "Upgrade: websocket" -H "Connection: Upgrade" \
  http://127.0.0.1:8080/app/YOUR_APP_KEY

sudo supervisorctl tail -f huwutong-reverb:huwutong-reverb_00
```

## 3. D-02 · HTTPS 证书 + Sanctum 域 + Nginx 反代

详见补充文档：[docs/deploy-https.md](./deploy-https.md)。

### 3.1 获取 SSL 证书

```bash
sudo apt update && sudo apt install -y certbot python3-certbot-nginx
# DNS A/AAAA 已指向本机后再执行
sudo certbot certonly --nginx -d 88.huwutong.com -d www.huwutong.com
sudo certbot renew --dry-run
```

### 3.2 部署 Nginx 配置

模板：`deploy/nginx/production-https.conf`

```bash
sudo cp deploy/nginx/production-https.conf /etc/nginx/sites-available/huwutong
sudo ln -sf /etc/nginx/sites-available/huwutong /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
```

要点：

- `443` 终止 TLS；`/app` 反代到 `127.0.0.1:8080`（Reverb）
- `fastcgi_param HTTPS on` + `X-Forwarded-Proto` 供 Laravel 识别 HTTPS
- 防火墙只开放 `80/443`，**不开放 8080**

### 3.3 强制 HTTPS 与 Sanctum

`FORCE_HTTPS=true` 已写入 `.env.production.example`，配合 `TrustProxies` 与 URL 生成强制 HTTPS。

```ini
APP_URL=https://88.huwutong.com
FORCE_HTTPS=true
TRUSTED_PROXIES=*

SESSION_DRIVER=redis
SESSION_DOMAIN=.huwutong.com
SESSION_SECURE_COOKIE=true
SESSION_SAME_SITE=lax

SANCTUM_STATEFUL_DOMAINS=88.huwutong.com,www.huwutong.com,admin.huwutong.com,portal.huwutong.com
FRONTEND_URL=https://88.huwutong.com
CORS_ALLOWED_ORIGINS=https://88.huwutong.com,https://www.huwutong.com,https://portal.huwutong.com
```

Windows 本地预写：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/apply-production-https.ps1 -Domain 88.huwutong.com
php scripts/verify-https-config.php
```

### 3.4 验证 HTTPS

```bash
curl -I https://88.huwutong.com
curl -sI https://88.huwutong.com | grep -i strict-transport
curl -I https://88.huwutong.com/api/health/ready
curl -i -H "Upgrade: websocket" -H "Connection: Upgrade" \
  https://88.huwutong.com/app/YOUR_APP_KEY
curl -c /tmp/cookies.txt -I https://88.huwutong.com/sanctum/csrf-cookie
```

## 4. D-03 · 真实支付接入

补充说明见 [docs/payment-setup.md](./payment-setup.md)。上线前可用：

```bash
php scripts/verify-payment-sms-config.php
```

### 4.1 支付宝

1. [支付宝开放平台](https://open.alipay.com) 创建应用，开通电脑网站支付 / 当面付  
2. 异步通知：`https://88.huwutong.com/api/payment/alipay/webhook`  
3. 同步跳转：`https://88.huwutong.com/portal/orders`

```ini
PAYMENT_DRIVER=alipay
ALIPAY_ENABLED=true
ALIPAY_SANDBOX=false
ALIPAY_APP_ID=
ALIPAY_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\n...\n-----END RSA PRIVATE KEY-----"
ALIPAY_PUBLIC_KEY="-----BEGIN PUBLIC KEY-----\n...\n-----END PUBLIC KEY-----"
ALIPAY_NOTIFY_URL=https://88.huwutong.com/api/payment/alipay/webhook
ALIPAY_RETURN_URL=https://88.huwutong.com/portal/orders
```

也可在管理后台 → 系统设置 → 支付网关填写。

冒烟（沙箱或 0.01 元）：

```bash
php artisan tinker
```

```php
$invoice = \App\Models\Invoice::factory()->create(['amount' => 0.01]);
$manager = app(\App\Services\PaymentManager::class);
$manager->useDriver('alipay');
print_r($manager->charge($invoice));
```

### 4.2 Stripe（可选）

```ini
PAYMENT_DRIVER=stripe
STRIPE_ENABLED=true
STRIPE_PUBLIC_KEY=pk_live_xxxxx
STRIPE_SECRET=sk_live_xxxxx
STRIPE_WEBHOOK_SECRET=whsec_xxxxx
```

Webhook：`https://88.huwutong.com/api/payment/stripe/webhook`  
事件建议：`checkout.session.completed`、`invoice.paid`、`charge.refunded`

### 4.3 微信支付（可选）

```ini
WECHAT_APP_ID=
WECHAT_MCH_ID=
WECHAT_PAY_KEY=
WECHAT_PAY_SERIAL_NO=
```

### 4.4 Webhook 可达性

## 6. 首次部署（新服务器）

### 6.1 快速步骤

```bash
# 1) SSH
ssh root@YOUR_SERVER_IP

# 2) 依赖
sudo apt update && sudo apt install -y nginx postgresql redis-server supervisor \
  php8.3-fpm php8.3-cli php8.3-pgsql php8.3-mbstring php8.3-xml \
  php8.3-curl php8.3-bcmath php8.3-redis php8.3-zip php8.3-gd \
  certbot python3-certbot-nginx git unzip curl

# 3) PostgreSQL
sudo -u postgres psql -c "CREATE USER huwutong WITH PASSWORD 'STRONG_PASSWORD';"
sudo -u postgres psql -c "CREATE DATABASE huwutong OWNER huwutong;"
sudo -u postgres psql -d huwutong -c "CREATE EXTENSION IF NOT EXISTS vector;"

# 4) Redis
sudo systemctl enable --now redis-server

# 5) 代码
sudo mkdir -p /var/www && cd /var/www
sudo git clone https://github.com/YOUR_ORG/huwutong.git huwutong
cd huwutong
sudo git checkout main   # 或发布 tag

# 6) PHP 依赖（无 dev）
composer install --no-dev --optimize-autoloader --no-interaction

# 7) 环境
cp .env.production.example .env
php artisan key:generate
# 编辑 .env：DB_*、REVERB_*、支付/短信、APP_URL 等
vim .env

# 8) 迁移与基础种子
php artisan migrate --force
php artisan db:seed --class=SiteSettingsSeeder --force

# 9) 缓存
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache

# 10) 前端（先确认 .env 中 VITE_REVERB_*）
npm ci && npm run build

# 11) Nginx + 证书
sudo cp deploy/nginx/production-https.conf /etc/nginx/sites-available/huwutong
sudo ln -sf /etc/nginx/sites-available/huwutong /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo certbot certonly --nginx -d 88.huwutong.com -d www.huwutong.com
sudo nginx -t && sudo systemctl reload nginx

# 12) Supervisor
sudo cp deploy/supervisor/huwutong-reverb.conf /etc/supervisor/conf.d/
sudo cp deploy/supervisor/huwutong-worker.conf /etc/supervisor/conf.d/
sudo supervisorctl reread && sudo supervisorctl update
sudo supervisorctl start huwutong-reverb:* huwutong-worker:*

# 13) 存储与权限
php artisan storage:link
sudo chown -R www-data:www-data storage bootstrap/cache public/build
sudo chmod -R 775 storage bootstrap/cache

# 14) Cron（见第 8 节）
# 15) 验证
php scripts/verify-production.php
```

### 6.2 部署用户建议

- 创建 `deploy` 用户用于 GitHub Actions SSH（见 `.github/workflows/deploy-vps.yml`）。
- `deploy` 具备对 `/var/www/huwutong` 写权限，以及有限的 `supervisorctl` sudo。

## 7. 版本更新与回滚

### 7.1 手动发布（推荐流程）

```bash
cd /var/www/huwutong
php artisan down --retry=60 --secret=hwt-ops-$(date +%Y%m%d)

# 可选：发布前备份
php artisan db:backup   # 若已配置；或 pg_dump

git fetch --tags
git checkout vX.Y.Z

composer install --no-dev --optimize-autoloader --no-interaction
npm ci && npm run build
php artisan migrate --force

php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache

sudo supervisorctl restart huwutong-worker:*
sudo supervisorctl restart huwutong-reverb:*

php artisan up
curl -fsS https://88.huwutong.com/api/health/ready
php scripts/verify-production.php
```

### 7.2 GitHub Actions（VPS）

工作流：`.github/workflows/deploy-vps.yml`

1. GitHub → Actions → **Deploy VPS Production** → Run workflow  
2. 输入 `version`（如 `v1.2.0`），可选 `dry_run`  
3. Secrets：`VPS_SSH_KEY`；环境 `production`  
4. 脚本会：`down` → checkout → composer/npm → migrate → cache → restart worker → `up` → `verify-production.php`

### 7.3 回滚

```bash
cd /var/www/huwutong
php artisan down --retry=60

git checkout vPREVIOUS.TAG
composer install --no-dev --optimize-autoloader --no-interaction
npm ci && npm run build

# 仅当新版本迁移可安全回滚时才执行；否则恢复 pg_dump
# php artisan migrate:rollback --step=N --force

php artisan config:cache && php artisan route:cache && php artisan view:cache
sudo supervisorctl restart huwutong-worker:* huwutong-reverb:*
php artisan up
curl -fsS https://88.huwutong.com/api/health/ready
```

**原则**：破坏性迁移上线前必须先备份；无法 rollback 时用 `pg_dump` 恢复。
