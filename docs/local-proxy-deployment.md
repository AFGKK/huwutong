# 本地 License 代理模式 (M3-12)

## 概述

本地 License 代理模式用于**大型企业内网无外网场景**。
企业内网部署本地代理节点，内网设备的 License 验证请求不经过公网，
代理节点完成离线验证或缓存验证，定期与云端同步。

## 代理节点部署步骤

### 1. 在管理后台注册代理节点
- 登录互物通管理后台 → 系统管理 → 本地 License 代理
- 点击「注册代理」，填写节点名称、内网地址
- 系统生成 `register_token` 和 `api_key`

### 2. 部署代理软件
代理节点需运行一个轻量级 HTTP 服务，支持以下端点：

| 端点 | 说明 |
|---|---|
| `POST /api/v1/heartbeat` | 心跳上报（每60s） |
| `GET /api/v1/config` | 获取配置 |
| `POST /api/v1/validate` | License 验证 |
| `POST /api/v1/sync-logs` | 同步激活日志 |

### 3. 激活节点
- 运营人员审批后，将 `register_token` 发给代理节点
- 代理节点调用激活接口完成激活
- 激活后节点状态变为 `active`

### 4. License 验证流程

```
内网设备请求验证
       │
       ▼
  ┌──────────┐     在线?     ┌──────────┐
  │ 本地代理   │ ──────yes──→ │ 云端验证   │
  │ 接收请求   │              │ (HTTPS)   │
  └─────┬────┘              └────┬─────┘
        │ no                     │
        ▼                        ▼
  ┌──────────┐              ┌──────────┐
  │ 缓存检查   │              │ 返回结果  │
  └─────┬────┘              └──────────┘
        │
   ┌────┴────┐
   │ 有效?    │
   └────┬────┘
        │
   ┌────┴────┐
   │ 返回结果  │
   │ + 记录日志│
   └─────────┘
```

## 配置项

| 配置 | 默认值 | 说明 |
|---|---|---|
| `sync_mode` | poll | 同步模式: poll/push |
| `sync_interval_seconds` | 300 | 配置同步间隔 |
| `heartbeat_interval_seconds` | 60 | 心跳间隔 |
| `cache_ttl_seconds` | 86400 | License缓存TTL(24h) |
| `max_cached_licenses` | 1000 | 最大缓存数 |
| `allow_offline_activation` | true | 允许离线激活 |

## 管理命令

```bash
# 查看节点列表
php artisan local-proxy:list --tenant=1

# 清理过期数据
php artisan local-proxy:cleanup
php artisan local-proxy:cleanup --dry-run  # 预览

# 强制同步配置到节点
php artisan local-proxy:sync --node=1
```
