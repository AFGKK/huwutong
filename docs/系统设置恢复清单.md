## 快速恢复命令

```bash
# 1. 补全所有系统设置项（不覆盖已有值）
php scripts/restore-system-config.php --apply-branding

# 2. 恢复 CMS 页面为互物通完整版并发布
php import_pages.php --force

# 3. 清除配置缓存
php artisan cache:clear
```

## 二、需手动重新填写的配置（密钥/凭证类）

> ⚠️ 这些值**无法从 Seeder 恢复**，必须在后台重新填写或从备份/密钥管理系统找回。

### 🔴 高优先级（影响核心功能）

- [ ] **DeepSeek API Key** — AI 对话、智能客服（若已丢失需重新申请）
- [ ] **Logo / Favicon** — 品牌展示（上传图片）
- [ ] **ICP 备案号 / 公安备案** — 合规展示
- [ ] **云存储凭证** — Access Key、Secret、Bucket、Endpoint（文件上传）
- [ ] **SMTP 密码** — 邮件发送（若不用 log 驱动）

### 🟡 中优先级（按需启用）

- [ ] **支付宝支付** — App ID、私钥、公钥、回调 URL
- [ ] **微信支付** — AppID、商户号、API 密钥
- [ ] **Stripe** — 公钥、私钥、Webhook Secret
- [ ] **PayPal** — Client ID、Secret
- [ ] **阿里云短信** — AccessKey、签名
- [ ] **腾讯云短信** — AppID、AppKey、签名
- [ ] **OAuth 登录** — 微信/QQ/Google/GitHub 等 AppID 和 Secret

### 🟢 低优先级（可选）

- [ ] **OpenAI / Claude / 通义 / 文心 / GLM** API Key
- [ ] **CDN 域名**
- [ ] **SEO 分享图 (OG Image)**
- [ ] **JSON-LD 结构化数据**
- [ ] **社交链接** (GitHub、Twitter、微信公众号)

## 五、防止再次误重置

1. **创建测试库隔离**：添加 `.env.testing`，测试库使用 `huwutong_testing`
2. **禁止对正式库执行** `migrate:fresh`
3. **定期备份**：`mysqldump -u root -p huwutong > backup_YYYYMMDD.sql`
4. **运行测试时使用**：`php artisan test`（已配置 SQLite 内存库）
