## 7. 开发排期建议

### 第一阶段（2 周）— 测试覆盖 + 紧急修复

```
第1周: IM 集成测试（3天）+ 电商流程测试（2天）
第2周: 空数据接口修复（0.5天）+ 轻量控制器完善（1天）
       + 推广员自助上传素材（1.5天）+ 推广员申请审核（1天）
```

### 第二阶段（2 周）— 前台优化 + 功能完善

```
第3周: 前台营销页面完善（3天）+ 响应式适配（2天）
第4周: Blog/互物号测试（1天）+ 结算测试（1天）
       + IM WebSocket 优化（1天）+ 商品佣金UI优化（0.5天）
       + 文章编辑器体验优化（0.5天）
```

### 第三阶段（按需）— 性能 + 新功能

```
按需: E2E 测试（3-5天）
按需: 前端构建优化（1天）
按需: 数据库索引优化（1天）
按需: AI 推荐佣金 / 数据分析看板 / 多语言
```

### 总计

| 阶段 | 时间 | 工作量 |

| 第一阶段 | 2 周 | 8 人天 |
| 第二阶段 | 2 周 | 8 人天 |
| 第三阶段 | 按需 | 5-15 人天 |
| **合计** | **4 周 + 按需** | **~21-31 人天** |
